# NINJIN

星の落ちた島「ヨスガ諸島」を冒険する、HD-2D風のオープンワールドアクションRPG。
ブラウザで動き、**Chrome からアプリとしてインストール**できます（容量はとても小さいです）。

## あそびかた（スマホ）

1. Chrome でゲームのページを開く
2. メニュー（︙）→「アプリをインストール」または「ホーム画面に追加」
3. ホーム画面の NINJIN アイコンから起動（横向きで遊びます）

| 操作 | ボタン |
|---|---|
| 移動 | 画面左側をなぞる（スティック） |
| カメラ | 画面右側をなぞる |
| 攻撃 / 重撃 / 落下攻撃 | 右下の「攻撃」（長押しで重撃、空中で落下攻撃） |
| 元素スキル | E（長押しで別の使い方になるキャラも） |
| 元素爆発 | Q（エネルギーがたまると光る） |
| ジャンプ / 滑空 | 「跳」（空中でもう一度押すと滑空） |
| ダッシュ | 「走」を押し続ける |
| キャラ交代 | 右側の顔アイコンをタップ |
| 調べる・話す | 近づくと出るボタン |

パソコンでは WASD 移動、Shift ダッシュ、Space ジャンプ、J 攻撃、K 重撃、E / Q スキル、1〜4 交代、F 調べる、M マップ。

## マルチプレイ（2人）

1. ホスト：メニュー →「マルチプレイ」→「部屋を作る」→ 6文字の部屋コードを友達に送る
2. ゲスト：「マルチプレイ」→ コードを入力して「参加する」
3. 1人のときは4人を交代、2人のときはそれぞれ2キャラを操作します

つながらないときは Wi-Fi を切ってモバイル回線で試してください。

## 中身

- オリジナルキャラクター26人（★5 10人・★4 16人）。通常攻撃・重撃・落下攻撃・スキル・爆発・召喚・サポートなどの「型」と固有天賦つき
- 6元素（焔・潮・雷・霜・星・影）と15種類のオリジナル元素反応
- 祈願（キャラ・武器・常設、天井あり、課金なし）
- 育成：レベル・突破・天賦・武器強化・精錬・遺紋（装備5部位・8セット）・覚醒
- 探索：登る・滑空・泳ぐ、宝箱、星の欠片、星の像、元素の仕掛け、ワープ
- 元素の学び舎（15種類の元素反応の試練）、毎日の依頼、秘境4つ、ボス6体、星の塔12層、イベント「星海の螺旋」（マルチ対応・強化カード）

## 開発

```
npm install
npm run dev     # http://localhost:5173
npm run build   # dist/ に出力
```

GitHub Pages は「GitHub Actions」でも「Deploy from a branch」でも動きます（ブランチ公開のときは自動で `dist/` のビルド済みゲームに移動します）。変更したら `npm run build` して `dist/` もコミットしてください。
